Redesigning Item Selection Experience on Zomato
Problem

Users face decision uncertainty due to mismatch between displayed images and actual food, along with lack of clear item-level information.

User Insights
Study conducted with 30 users
93% experienced mismatch between images and delivered food
83% rely on images but report low trust
70% do not check nutritional information due to poor visibility
Solution

Designed an MVP to improve decision-making by:

Prioritizing real restaurant images
Improving item-level information clarity
Enhancing review filtering
Results
Average rating: 8.6/10
80% users rated ≥ 8
Users preferred real images and structured information
Improved perceived trust and clarity
Key Takeaways
Visual authenticity is critical for trust
Better information clarity improves decision confidence
Interface changes can reduce decision friction
